            Sandbox modes

            How far an app's tasks reach. Agneta has two modes, the same for every engine, and three things decide what a task gets.

            This app's grant Not connected

            1. Contained

            2. Developer access

            1. The grant is the ceiling. The user picks it for this app in Agneta's approval window, and can change it in Settings → Apps.
            2. The app may ask for less, never more. Each session asks for a mode in its policy; asking above the grant is refused, with Agneta's reason.
            3. The engine must be able to provide it. Each engine declares what it can provide on each provider; a mode it can't provide is refused, with why.
